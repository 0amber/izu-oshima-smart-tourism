# 05 荷物があるなら初日は三原山に行かない

- 三原山（山頂口〜火口）は未舗装で、キャリーケースを持って歩ける場所ではない（09参照）。バスにも手荷物ルールがある（02参照）。
- 現実的な組み方（1泊2日・三原山温泉泊の場合）：
  1. **1日目**：港→椿・花ガーデン（港から約8分・平坦・荷物ありでも回れる）→ 昼の便でホテル前へ → 荷物を預ける／チェックイン
  2. **2日目**：朝の上りで山頂口へ → 三原山 → 昼の下りでホテルへ戻り荷物回収 → 午後の最終便で港 → 船
- 逆に、荷物がなければ1日目から山頂へ直行できる（10時台の便で山頂口10:45頃着など）。
- AIへの示唆：**「荷物あり／なし」で旅程を分岐**させ、荷物ありの日は「平坦・バス停至近・屋根or休憩所あり」のスポットを選ぶ。

出典：チーム検討（2026-08-16〜17）＋大島バス時刻表。2026-08-18時点。
