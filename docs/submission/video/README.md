## 使い道
1. **First Stage収録（フォーム6-2、Zoom）**：この映像を画面共有で流しながら下の台本を読む。映像は無音のまま（事務局ルール：音声作品以外は無音）
2. **3-8 デモの操作動画（任意・60秒以内・無音）**：`record_promo.py` の `run_poc` だけを録れば60秒版になる
3. チーム・審査員向け共有

## ナレーション台本（約120秒・約560字。映像の秒に合わせて読む）

| 秒 | 画面 | 読み上げ |

| 0–8 | 港・問いかけ | その旅程、バスは本当にありますか？　SBC.別班連携チームの「大島スマートコース」です。 |
